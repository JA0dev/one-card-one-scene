# 다음 작업

## 방향: 포스트잇이 가득한 식탁
작가가 식탁 위에 씬 포스트잇을 펼쳐 놓고 작업하듯 쓰는 앱이다. 감성보다 사용성이 우선이다.

- 식탁에서 하는 일: 전체를 한눈에 본다, 떠오르면 바로 한 장 써서 붙인다, 사이에 끼워 넣는다, 앞면을 그 자리에서 고친다, 옮긴다, 애매한 건 옆에 치워둔다, 한 장 집어 들고 쓰다가 제자리에 둔다.
- 디지털이라 더 할 수 있는 일: 본문을 길이 제한 없이 쓴다, 조건별로 골라 보고 원래 순서로 돌아온다, 자르고 붙인다, 되돌린다, 전체를 이어서 읽는다, 어디서나 같은 식탁을 쓴다.
- 카드는 씬을 조망하는 짧은 표현이고 본문은 길이 제한이 없다.
  - 카드 크기는 일정하게 둔다. 입력은 자유롭게 받고, 보드에는 제목과 요약을 정해진 줄 수만 보여준다. 본문이 길어져도 카드는 커지지 않는다.
  - 밀도를 높여도 모바일 터치 영역과 가독성은 줄이지 않는다.
- "앞면/뒷면"은 설명용 비유로만 쓰고 화면 문구로는 쓰지 않는다. 화면은 `카드 → 집필`, 보조 기록은 `노트`다.
- 진행 단계는 글자 없이 색 점으로 보여준다(사용자 결정). 팔레트는 '노을 구름'(복숭아 → 코랄 → 장밋빛 → 라벤더, 선택은 하늘색).
- 넣지 않는 것: 태그, 사용자가 붙이는 색 라벨, 카드 연결선, 자동 요약.

## 완료
- 상위 탭은 `펼쳐보기 / 이어보기`(아이콘). 집필은 카드를 열어 들어가는 하위 화면이다.
- 이전/다음 씬 버튼에 순서와 제목이 보인다. 마지막 씬에서는 `구성으로 · 카드 돌아보기`로 바뀐다.
- 펼쳐보기로 돌아오면 쓰던 카드가 선택되고 키보드 초점이 그 카드에 있다.
- `노트` 버튼과 메모 대화상자가 있다. 메모가 맨 위, 시점·장소·시간이 아래다.
- 씬 나누기·합치기를 메뉴로 옮겼다.
  - `커서 위치에서 나누기`는 집필 `…` 메뉴에만 있다.
  - `다음 씬과 합치기`는 카드 메뉴와 집필 메뉴에 있고, 합칠 대상의 번호와 제목을 보여준다.
- 보류함을 휴지통으로 합쳤다. 휴지통: 되돌리기, 영구 삭제, 비우기. 카드 메뉴의 이동은 `위치 바꾸기` 하나로 합쳤다.
- 작품 메뉴는 설정(⚙)으로 바꾸고 본문 서식·화면을 `보기` 한 화면으로 합쳤다. 저장 아이콘은 문제가 있을 때만 보인다.
- 보드에서 카드 정보 편집, 선택한 카드 다음에 새 카드.
  - 카드 메뉴 `카드 정보 편집`: 보드 안에서 제목·요약을 고친다. 입력은 바로 저장된다. 제목에서 Enter → 요약, 요약에서 Enter → 마침, Esc → 시작 전 값으로 되돌림, 카드 밖을 누르면 마침. 한글 조합 중 Enter는 무시한다.
  - 편집 중에는 그 카드의 드래그와 집필 이동이 막힌다.
  - 카드 메뉴 `다음에 새 카드`(사용 중 카드만)와 `+` 버튼은 새 카드를 보드에서 편집 상태로 연다. 빈 새 카드에서 Esc를 누르면 카드가 사라진다.
  - 새 카드가 검색·단계 필터에 가려지면 필터를 해제하고 알린다.
- 집필 화면: 상단 `카드 01` 상자를 번호 `01`로 줄였다. 요약 칸은 내용 높이에 맞추고 제목·요약과 구분선 사이 여백을 줄였다.
- 팔레트 '노을 구름' 적용: 진행 단계 색 점(카드·목차·흐름 막대), 선택 카드 하늘색 테두리, 따뜻한 종이색 배경과 다크 모드.
- 확인된 사실: 모바일 집필 화면에서 끝까지 스크롤하면 다음 씬 버튼은 탭바에 가려지지 않는다. 버그가 아니다.

## 남은 작업 (순서대로)
디자인 모드 제안(보드에 장 구분, 집필 화면 옆 카드 목록, 이어보기 장별 목차)을 기준으로 한다. 파란 포인트색·인물별 색 점·실시간 "쓰는 중" 표시·큰 파란 `+` 버튼은 가져오지 않는다.

### 1. 장
- 장은 카드를 담는 상자가 아니라 카드 사이에 꽂는 경계다. 이야기 순서는 하나로 이어지고, 끌어서 옮기기·이어보기·나누기·합치기는 그대로 동작한다.
- 장은 선택 사항이다. 장이 없는 작품은 지금처럼 보이고, 처음 장을 나누면 장 제목이 나타난다.
- 보드: `1장 도착` 제목, 장 제목 바로 고치기(Enter 완료), 장 메뉴(이름 바꾸기 · 위에/아래에 새 장 · 앞 장과 합치기 · 장 삭제), 카드 사이에서 장 나누기, 맨 아래 `새 장`.
- 장 순서 바꾸기: PC는 장 제목 끌기, 모바일은 `장 편집` 목록.
- 장 조작은 `lib/scene-ops.ts` 순수 함수와 테스트로 만든다. 필터로 빈 장은 숨기고, 내보내기에 장 제목을 넣는다.

### 2. 보드 정돈
- 카드 아래 줄을 `인물 · 장소 | 글자 수`로 통일하고 빈 공간을 줄인다. 장 끝에 빈 `+` 칸을 두고, 검은 `+` 버튼의 무게를 줄인다.
- 모바일 보드 밀도: 두 열 카드로 한 화면에 더 많이 보이게 한다. 터치 영역은 유지한다.

### 3. 집필 화면
- 왼쪽에 같은 장의 카드 목록, `‹ 펼쳐보기` 돌아가기, `인물 · 장소 · 시간` 한 줄과 요약 상자.

### 4. 이어보기
- 장별로 접히는 목차와 `카드로 열기`.

### 5. 시점 인물 · 장소 필터
- 이야기 순서는 그대로 두고 조건에 맞는 씬만 보여준다. 기존 단계 필터가 있는 보기 옵션 메뉴에 함께 둔다.
- 값 목록은 입력된 `pov`, `place`에서 만든다. `시점 인물`은 등장인물이 아니다. `time`은 자유 입력이라 정렬하지 않는다.
- 필터가 켜져 있으면 보드에서 알 수 있어야 하고, 한 번에 해제할 수 있어야 한다.

### 이후 검토
- 그룹 보기(시점 인물별·장소별로 묶어 보기): 실제로 필요해질 때만. 그룹 화면에서 끌면 이야기 순서가 어떻게 바뀌는지 규칙부터 정한다.
- 짧은 카드 전환 효과: 200ms 이내, `prefers-reduced-motion`을 지킨다.
- 설정 메뉴 `내려받기 · 백업`과 열리는 화면 제목 `원고 내보내기`를 한 이름으로 맞춘다.
