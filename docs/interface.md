# 화면과 동작

## 헤더 (모든 화면 공통)
- 왼쪽: 작품 이름 ▾ → 작품 바꾸기 · 새 작품 · 예시 작품 열기 · 작품 이름 바꾸기 · 작품 삭제
- 가운데: `펼쳐보기 / 이어보기` (모바일은 아래 탭바: 펼쳐보기 · + · 이어보기)
- 오른쪽(순서 고정): 저장 상태 · 렌즈(펼쳐보기·이어보기에서) · 찾기(⌘K) · 설정 · +
  - 저장 상태: `기기에 저장됨`(로그인 전) · `동기화 중` · `동기화됨` · `오프라인 · 기기에 저장됨` · `동기화 문제` · `계정 확인 필요`. 누르면 계정·동기화 설정.
  - `+`: 펼쳐보기·이어보기에서는 마지막 장 끝에 새 카드(보드에서 바로 편집), 집필에서는 지금 카드 다음에 새 카드를 만들고 연다.

## 펼쳐보기 (보드)
- 장마다 `N장 제목 · 진척 막대 · 카드 수 · ⋯` 줄과 카드 격자. 장 끝에 `+` 칸(끌어 놓을 자리이기도 함).
- 장 제목을 누르면 그 자리에서 고친다(Enter 완료, Esc 취소). 장 메뉴: 이름 바꾸기 · 위/아래에 새 장 · 앞 장과 합치기 · 장 순서 바꾸기… · 장 삭제(장 구분만 / 카드까지 휴지통).
- 장이 없는 작품은 카드만 보이고 아래에 `장으로 나누기`. 장이 있으면 아래에 `+ 새 장`. 휴지통에 카드가 있으면 오른쪽 아래에 `휴지통 N`.
- 카드: 번호 · 단계 색 점 · 제목 · 요약(3줄) · (설정에 따라) 인물·장소 | 글자 수. 높이는 고정.
  - 누르면 집필. 색 점을 누르면 단계 고르기. ⋯ 메뉴: 제목·요약 고치기 · 다음에 새 카드 · 여기서 장 나누기 · 옮기기… · 다음 카드와 합치기 · 복제 · 여러 장 고르기 · 휴지통으로.
  - 카드 사이 틈에 마우스를 올리면 `+`(여기에 새 카드)와 `✂`(여기서 장 나누기).
  - 끌어서 옮기기: 다른 장의 카드 위나 장 끝 칸에 놓으면 그 장으로 간다. 모바일은 길게 눌러 끈다.
  - 보드에서 제목·요약 고치기: Enter로 다음 칸·마침, Esc로 되돌림, 바깥을 누르면 마침. 새로 만든 빈 카드는 Esc나 바깥 누르기로 사라진다.
- 여러 장 고르기: Shift/⌘/Ctrl+클릭 또는 카드 메뉴. 아래 막대에서 단계 · 옮기기 · 휴지통, Esc로 끝. 고른 카드 하나를 끌면 모두 함께 옮겨진다.
- 휴지통: 30일이 지나면 자동으로 지워진다. 되돌리기 · 영구 삭제 · 휴지통 비우기(기기 복구 사본을 남긴 뒤).
- 되돌리기: 옮기기 · 삭제 · 합치기 · 나누기 · 장 조작 뒤 알림의 `되돌리기`.

## 렌즈
- 진행 단계 · 시점 인물 · 장소를 여러 개 골라 조합한다. 값 목록은 입력된 내용에서 만들고(쉼표로 여러 이름), 많이 쓴 순서.
- 맞지 않는 카드: `나머지 흐리게`(기본, 이야기 순서와 장 구조가 그대로 보임) / `나머지 숨기기`.
- 켜진 조건은 보드·이어보기 위에 칩으로 보이고, 하나씩 또는 `모두 해제`로 끈다. 찾기에서 `보드에서 "…" 카드만 보기`를 고르면 검색어도 렌즈 칩이 된다.

## 집필
- 데스크톱: 왼쪽에 모든 장의 카드 목록(지금 장만 펼침, 다른 장은 눌러서 펼침, 다른 장 카드로 넘어가면 그 장이 펼쳐짐), 가운데 종이. 돌아가기는 헤더의 `펼쳐보기` 탭. 1080px 이하에서는 목록을 숨기고, 헤더 탭이 사라지는 모바일(760px 이하)에서만 종이 위에 `‹`.
- 종이 위 줄: `N장 · 3 / 4` · 단계 점 · 노트 · ⋯(커서 위치에서 나누기 · 다음 카드와 합치기 · 옮기기… · 복제 · 저장 이력 · 휴지통으로) · 이전/다음.
- 번호 · 제목 · `시점 인물 / 장소 / 시간`(그 자리에서 고침) · 요약 상자 · 본문. 아래에 글자 수와 `다음 장면`(마지막 카드면 `펼쳐보기로 돌아가기`).
- 단축키: ⌥⌘↓ / ⌥⌘↑ (Windows Ctrl+Alt+↓/↑) 다음·이전 카드. ⌘K 찾기.
- 카드마다 쓰던 스크롤 위치를 기억한다. 본문은 1분마다 이전 모습을 저장 이력에 남긴다(최근 50개).

## 이어보기
- 데스크톱: 왼쪽 목차(장별로 접기, 지금 읽는 씬 표시, 전체 글자 수), 가운데 원고. 모바일은 `목차` 버튼.
- 장 제목, 씬 머리줄(`01 제목 ────── 카드로 열기`), 본문은 그 자리에서 고칠 수 있다. 렌즈가 켜져 있으면 맞는 씬만.

## 설정
- 보기: 화면(기기 설정/밝게/어둡게) · 카드(카드/제목만, 인물·장소·글자 수) · 본문 글꼴 · 글자 크기 · 줄 간격 · 미리보기
- 내보내기 · 백업: Word · Markdown · 텍스트(장·씬 순서, 휴지통 제외) / 백업 저장(모든 작품) · 가져오기(.json · .md · .txt, 항상 새 작품) / 기기 복구 사본
- 계정 · 동기화: 로그인 · 회원가입 · 비밀번호 재설정 / 동기화 상태 · 지금 동기화 · 로그아웃

## 저장과 동기화
- 쓰는 즉시 기기(IndexedDB)에 저장. 로그인하면 작품 단위로 Supabase와 맞춘다(바뀐 작품만, 실시간 알림으로 다른 기기 변경을 곧바로 받음).
- 같은 작품을 두 기기에서 동시에 고치면 서버 내용이 원래 자리에, 이 기기 내용은 `· 이 기기 사본` 작품으로 남는다.
- 이 기기에 다른 계정의 원고가 있으면 동기화를 멈추고, 설정에서 `이 계정 원고로 바꾸기`(복구 사본 남김)를 고를 수 있다.
- 작품 삭제·휴지통 비우기·충돌·계정 변경 전에는 기기 복구 사본(최근 30개)을 남긴다.
- 예전 앱(scene-studio-v1)의 원고가 기기에 있으면 처음 열 때 한 번 옮겨 온다.

## 서버 설정 (Supabase)
`supabase/migrations/002_scene_projects.sql`을 SQL Editor에서 한 번 실행한다. 작품마다 한 줄(`scene_projects`), 저장은 `save_scene_project`(번호표가 맞을 때만), 삭제는 `delete_scene_project`(삭제 표시), 이전 판은 작품마다 50개. 예전 앱의 표(`scene_workspaces`)는 원고를 백업 파일로 옮긴 뒤 지웠다. 계정(`auth.users`)은 그대로다.
주소와 공개 키는 `.env`의 `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`로 바꿀 수 있다(`.env.example` 참고).
