# 다음 작업

## 방향: 포스트잇이 가득한 식탁
작가가 식탁 위에 씬 포스트잇을 펼쳐 놓고 작업하듯 쓰는 앱이다. 감성보다 사용성이 우선이다.
- 식탁에서 하는 일: 전체를 한눈에 본다, 떠오르면 바로 한 장 써서 붙인다, 사이에 끼워 넣는다, 앞면을 그 자리에서 고친다, 옮긴다, 묶음(장)으로 나눈다, 한 장 집어 들고 쓰다가 제자리에 둔다.
- 디지털이라 더 할 수 있는 일: 본문을 길이 제한 없이 쓴다, 조건으로 골라 보되 순서는 그대로 둔다, 되돌린다, 전체를 이어서 읽는다, 어디서나 같은 식탁을 쓴다.
- 카드 크기는 일정하다. 본문이 길어져도 카드는 커지지 않는다.
- 넣지 않는 것: 태그, 사용자가 붙이는 색 라벨, 카드 연결선, 자동 요약.

## 완료: 재구축 (2026-09)
- 새 구조(`src/domain · data · state · ui · features`), 데이터 모델 v2(장, 단계 키, 휴지통 시각), 테스트 25개.
- 작품 단위 Supabase 동기화(번호표 저장, 충돌 시 양쪽 보존, 실시간 알림, 계정 확인), 새 SQL.
- 디자인 제안(PDF) 기준 화면: 장별 보드, 집필 화면 옆 카드 목록, 이어보기 장별 목차. 팔레트 '노을 구름'.
- 개선: 렌즈(단계·인물·장소, 흐리게/숨기기), 장별 진척 막대, 색 점으로 단계 바꾸기, 카드 사이 틈(+/✂), 되돌리기 통일, 여러 장 고르기, 찾기(⌘K), 카드/제목만 보기.
