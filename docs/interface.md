# 집필 화면과 스타일 구조

상위 탭은 구성과 전체원고 두 개입니다. 집필은 카드를 열어 진입하는 하위 화면이며 구성 탭으로 돌아갈 수 있습니다.

- 카드 번호를 누르거나 구성 탭을 선택하면 보드의 해당 카드로 돌아갑니다. 현재 검색·단계 필터는 유지합니다. 필터에 가려진 카드를 강제로 노출하지 않습니다.
- 이전·다음 씬 버튼에는 순서와 제목이 나타납니다. 버튼 및 상·하단 스와이프 이동은 새 씬 맨 위에서 시작합니다. 카드에서 다시 여는 경우 저장된 집필 위치를 복원합니다.
- 노트 버튼은 작업 메모를 먼저 보여주는 대화상자를 엽니다. 시점·장소·사건 시간도 같은 곳에서 편집합니다. 저장은 기존 씬 데이터와 저장 큐를 사용합니다.
- 씬 나누기와 합치기는 노트가 아니라 메뉴에 있습니다. `커서 위치에서 나누기`는 본문 커서가 있는 집필 화면 `…` 메뉴에만 있습니다. `다음 씬과 합치기`는 카드 메뉴와 집필 메뉴에 있으며, 합칠 대상의 순서와 제목을 함께 보여줍니다. 합쳐진 원래 카드는 보류함으로 옮겨집니다.
- 보관함 선택은 `사용 중 / 보류함 / 휴지통`입니다. 상위 탭의 `전체원고`와 이름이 겹치지 않도록 `원고` 대신 `사용 중`을 씁니다.
- 노트를 닫으면 노트 버튼으로 키보드 초점이 돌아갑니다.

## 스타일

`app/globals.css`는 스타일 진입점입니다.

- `app/styles/tokens.css`: 밝은/어두운 테마 색상 및 자체 호스팅 폰트
- `app/styles/workspace.css`: 기존 작업실·카드·반응형 레이아웃. 이전 사이드바·집중모드 선택자와 동일 조건의 덮어쓴 선언을 제거했습니다. 일부 서로 다른 선택자 사이의 캐스케이드는 기존 외관을 유지하기 위해 남아 있습니다.
- `app/styles/scene.css`: 노트와 씬 이동 UI

CSS를 수정할 때 기존 선언 위치를 변경하고 마지막에 덮어쓰기 블록을 추가하지 않습니다.
